# מסד הנתונים (Supabase)

הקבצים ממוספרים לפי סדר ההרצה. **כל קובץ בטוח להרצה חוזרת** (יוצר רק מה שחסר).

| קובץ | מה הוא מוסיף |
|---|---|
| `010-schema.sql` | המסד המלא (כולל 1.3 עד 1.7 שלב ב). בהתקנה חדשה מספיק להריץ אותו ואת 017c ו-018 |
| `013-notices.sql` | הודעות רשמיות לאישור (1.3) |
| `014-signatures.sql` | חתימות וכתב הסמכה (1.4) |
| `015-workers.sql` | פנקס עובדים, הדרכות, ציוד (1.5) |
| `016-field.sql` | נוכחות, עבודה בגובה, ביקורת באתר (1.6) |
| `017a-field.sql` | עבודה בלי קליטה, ליקויים (1.7 א) |
| `017b-field.sql` | דוח בקר, תאונות (1.7 ב) |
| `017c-mail.sql` | מיילים מהשרת וגיבוי חודשי (1.7 ג). דורש pg_cron ו-pg_net |
| `018-schema-check.sql` | בדיקת התקנה במסך "הגדרות ותצוגה" |

## בדיקת התקנה
במסך **הגדרות ותצוגה** (מנהל שירות) מופיע כרטיס "בדיקת התקנה". הוא משווה את המסד החי לרשימה ב-`js/schema-expected.js`
ומראה איזה קובץ צריך להריץ אם משהו חסר.

אחרי כל שינוי SQL מריצים `bash scripts/gen-schema-expected.sh` (Postgres מקומי) ומעדכנים את `js/schema-expected.js` באותו PR.
